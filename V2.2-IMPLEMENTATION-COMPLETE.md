## 🎯 Key Features

### Two-Stage AI Pipeline
1. **Stage 1 (Analysis)**: Gemini or Groq extracts relevant info from documents
2. **Stage 2 (Writing)**: Llama 3.3 70B or Llama 4 Scout 17B generates high-quality content

### Smart Provider Selection
```javascript
// Analyzer priority (prefer large context)
["gemini", "groq"]

// Writer priority (prefer quality)
["openrouter", "groq", "gemini"]

// Speed mode (prefer fast)
["groq", "openrouter", "gemini"]
```

### Semantic Search (v2.2)
- Transformers.js with `all-MiniLM-L6-v2` model (~25MB)
- Hybrid search: 70% semantic + 30% keyword

### OCR Support (v2.2)
- Tesseract.js for scanned documents
- Progress tracking during OCR
- Confidence scoring

### Enhanced Export Formats (v2.2)
- Anki CSV flashcards
- Notion-compatible markdown
- Study checklist with progress tracking
- PDF with proper formatting

## 🚀 Usage Guide

### 1. Add API Keys
```
Minimum: 1 key (Gemini, OpenRouter, or Groq)
Recommended: 2 keys (Gemini + OpenRouter or Gemini + Groq)
Optimal: 3 keys (all three for maximum flexibility)
```

### 2. Upload Reference Material
- PDFs, DOCX, PPTX, images, text files
- Enable OCR for scanned documents
- Enable Semantic Search for better relevance

### 3. Define Course Structure
- Course name
- Modules (e.g., "Data Structures")
- Topics per module (e.g., "Arrays", "Linked Lists")

### 4. Generate
- Choose detail level (Brief or Detailed)
- Enable Speed Mode if using Groq
- Wait for generation (progress shown)

### 5. Export
- Copy to clipboard
- Download Markdown
- Download PDF
- Export Anki cards / Notion / Checklist
