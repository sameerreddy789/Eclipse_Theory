### 📊 Monitoring: Add Sentry Error Tracking & Performance Monitoring

**Overview**: Add comprehensive error tracking and monitoring.

**Features**:
- Sentry DSN
- error boundary
- error logging
- performance metrics
- session tracking.

**Tracked**:
- **Errors** (runtime, API, generation)
- **Performance** (generation time, API response, cache hit rates)
- **Events** (feature usage, failures, rate limits)

**Setup**:
- Add NEXT_PUBLIC_SENTRY_DSN and SENTRY_AUTH_TOKEN to .env.
